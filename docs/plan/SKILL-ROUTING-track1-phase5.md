# SKILL ROUTING: Track 1 - Phase 5 (Verification & Audit)

### Được phép sử dụng:
- **Testing & Verification:** Chạy Vitest, TypeScript compiler (`npm run typecheck`), và Vite production build (`npm run build`).
- **Audit Script:** Tạo hoặc chạy script audit mẫu kịch bản trong thư mục `tests/` hoặc `scripts/`.

### KHÔNG được phép sử dụng:
- Không bỏ qua bất kỳ lỗi TypeScript hay test failure nào.
- Không sửa đổi logic nghiệp vụ mà không có lý do kỹ thuật rõ ràng.
